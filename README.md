# 🎶 Record Company Database Project

Εργασία Εργαστηρίου Βάσεων Δεδομένων (2024–2025) . CEID Upatras 
Υλοποίηση σε **MySQL** και **Java (JDBC + GUI)**

---

## 📌 Περιγραφή
Η εφαρμογή αφορά τη **διαχείριση δισκογραφικών εταιρειών και μουσικών καλλιτεχνών**.  
Το σύστημα υποστηρίζει:
- Διαχείριση καλλιτεχνών (φυσικά πρόσωπα ή συγκροτήματα) και των συνεργασιών τους.
- Διαχείριση δισκογραφικών εταιρειών, παραγωγών, άλμπουμ και κομματιών.
- Καταγραφή κυκλοφοριών άλμπουμ.
- **Διαχείριση συναυλιών (concerts)**, με λειτουργίες για:
  - Προγραμματισμό / ακύρωση / επαναπρογραμματισμό συναυλιών.
  - Αυτόματη επιλογή κατάλληλου χώρου διεξαγωγής (venue) με βάση χωρητικότητα και βαθμολογία.
  - Δημιουργία ιστορικού συναυλιών με περισσότερες από **60.000 εγγραφές**.
- Καταγραφή ενεργειών DBA μέσω triggers (log).

---

## 🗂 Δομή Project

### Μέρος Α: Σχεδίαση ΒΔ & SQL
- Σχεσιακό σχήμα & δημιουργία πινάκων.
- Εισαγωγή δεδομένων για καλλιτέχνες, εταιρείες, παραγωγούς, άλμπουμ κ.ά.
- Stored Procedures:
  - Υπολογισμός βαθμολογίας χώρων.
  - Προγραμματισμός/ακύρωση/ενεργοποίηση συναυλιών.
  - Ανάθεση χώρου συναυλίας με βάση περιορισμούς.
  - Αναζητήσεις στο ιστορικό (με χρήση indexes).
- Triggers:
  - Καταγραφή ενεργειών DBA (log).
  - Έλεγχοι περιορισμών για συναυλίες (π.χ. μέγιστος αριθμός, χρονικά όρια).

### Μέρος Β: GUI (Java + JDBC)
- Γραφική Διεπαφή Χρήστη για πρόσβαση σε όλους τους πίνακες της ΒΔ.
- Προβολή, εισαγωγή, τροποποίηση και διαγραφή δεδομένων.
- Έλεγχος εγκυρότητας δεδομένων μέσω dropdown menus & λιστών.
- (Προαιρετικό) Προβολή διαθέσιμων χώρων διεξαγωγής με βαθμολογία.
